
# Tindahan ni Juan 🏪

A modern and responsive website for a fictional Filipino Sari-Sari Store, built as a Midterm Practical Examination project.

## 📌 Project Description

Tindahan ni Juan is a small neighborhood store that provides affordable everyday essentials, snacks, beverages, and household products.

The website showcases the store's identity, products, services, and contact information through a modern and responsive design.

## 🎨 Design Systems

### Color Palette (60-30-10 Rule)

| Percentage | Color | Hex Code | Usage |
|---|---|---|---|
| 60% | Cream | #F8F5E9 | Main background |
| 30% | Green | #246B45 | Secondary backgrounds |
| 10% | Yellow | #F5A623 | Accent and highlights |

Additional colors:

- Dark Background: #171D19
- Dark Surface: #25342A
- Main Text: #20251F

### Visual Style

**Neo-Brutalism + Bento Grid**

Design characteristics:

- Bold typography
- Thick borders
- Offset shadows
- Rounded product cards
- Organized grid layouts
- Strong color contrast
- Simple and clean navigation

## ♿ Accessibility and Contrast

Body text contrast was calculated using the WCAG contrast ratio formula.

| Text Color | Background | Contrast Ratio |
|---|---|---|
| #20251F | #F8F5E9 | 14.29:1 |
| #FFFFFF | #246B45 | 6.43:1 |
| #20251F | #F5A623 | 7.70:1 |

All listed combinations pass the WCAG AA requirement of 4.5:1 for normal text.

Contrast reference: https://webaim.org/resources/contrastchecker/
